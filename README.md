# POS Database System

SQL database coursework project for a point-of-sale system. The repository contains the schema script, member SQL contributions, data dictionary, sample table records, and the final report document.

## Highlights

- Designed relational tables for POS operations and supporting records.
- Prepared data dictionary and sample records for validation.
- Consolidated group SQL scripts into a complete database submission.

## Repository Structure

- `sql/` - database creation and contribution scripts.
- `docs/` - data dictionary, table records, and final report.

## Notes

This was completed as a university database technology group assignment and is published as portfolio evidence.
